## 项目简介
AnonNav 是一个简洁的导航搜索页面，旨在为用户提供便捷的搜索入口和自定义搜索引擎管理功能。用户可以通过选择不同的搜索引擎进行搜索，并且可以添加或删除自定义搜索引擎，满足个性化搜索需求。
